# מתג התחזוקה של אפליקציית נוי השדה

הקובץ `gate.json` שבמאגר הזה הוא **מתג החירום של האפליקציה**.
הוא קיים כדי שאפשר יהיה לעצור הזמנות מהאפליקציה תוך דקות, מכל מקום, מהטלפון — בלי מפתח, בלי חנות האפליקציות ובלי אף גורם חיצוני.

---

## איך עוצרים את האפליקציה (חירום)

1. פותחים כאן את הקובץ **`gate.json`**
2. לוחצים על אייקון העיפרון ✏️ (עריכה)
3. משנים `false` ל-`true`, וכותבים הודעה ללקוח:

```json
{
  "maintenance": true,
  "text": "האפליקציה בתחזוקה קצרה. אפשר להזמין כרגיל דרך האתר."
}
```

4. **Commit changes**

תוך דקות ספורות כל מי שפותח את האפליקציה יראה מסך תחזוקה עם כפתור להזמנה באתר.

## איך מחזירים לפעילות

אותו דבר, עם `false`:

```json
{
  "maintenance": false,
  "text": ""
}
```

---

## מה חשוב לדעת

- **האתר ואפליקציית ה-legacy לא מושפעים בכלל.** ההזמנות ממשיכות להיכנס דרכם — העסק לא נעצר, רק האפליקציה החדשה.
- **אם הקובץ הזה לא זמין, או שיש בו טעות כתיב — האפליקציה עובדת כרגיל.** המתג נכשל לכיוון הבטוח: רק `true` מפורש עוצר אותה.
- **שימו לב לתחביר:** מרכאות כפולות בלבד, בלי פסיק אחרי השורה האחרונה. אם משהו נשבר — האפליקציה פשוט תמשיך לעבוד.
- הטקסט מוצג ללקוחות כמו שהוא. כדאי לכתוב משהו מרגיע וקצר.

## למה זה כאן ולא ב-WordPress

יש גם מתג מקביל בשרת (`maintenance_mode`), אבל הוא תלוי בשינוי אצל ספק חיצוני.
המתג הזה בשליטה מלאה של נוי השדה. שני המקורות עובדים במקביל — מספיק שאחד מהם דולק.
